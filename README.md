# Personal Portfolio Website

This project is a personal portfolio website developed for ISDS 4125 at Louisiana State University. It features a hybrid layout: a single landing page covering my background, skills, experience, and contact information, with dedicated sub-pages for my resume and an individual project showcase.

**Live Site:** https://syphg.github.io/portfolio/

## Reflection

The most challenging part of this assignment was connecting the local files in my IDE to GitHub via Git. Moving between the IDE editor, the local command terminal, and the GitHub web interface felt disconnected, and I was confused when my initial push was rejected. I asked the agent why my local repository could not push to the remote branch directly and what commands were needed to resolve it. The agent explained that the remote repository contained an initial commit that did not exist on my computer, creating separate histories that Git blocked from merging automatically. Understanding the distinction between local tracking and remote refs helped me learn the difference between git add, git commit, and reconciling branches before running git push.
